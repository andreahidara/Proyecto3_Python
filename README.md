## 📋 Descripción del Proyecto

Este repositorio contiene la resolución de una batería completa de **40 katas y ejercicios prácticos en Python** correspondientes al Proyecto 3. El objetivo es consolidar el dominio de la sintaxis fundamental de Python, estructuras de datos nativas, control de excepciones, programación funcional y Programación Orientada a Objetos (POO).

## 🧠 Contenidos y Conceptos Aplicados

1. **Estructuras de Datos y Algoritmia Básica:**
   - Cadenas de texto: conteo de frecuencias de caracteres, manipulación, enmascaramiento y anagramas.
   - Listas y tuplas: filtrado, búsqueda de elementos duplicados, ordenación y operaciones vectoriales.
   - Diccionarios: conteo de frecuencias, búsquedas estructuradas y transformaciones.

2. **Programación Funcional y Funciones de Orden Superior:**
   - Uso de funciones `lambda`.
   - Transformaciones con `map()`.
   - Filtrado de colecciones con `filter()`.
   - Acumulaciones y reducciones con `functools.reduce()`.

3. **Manejo Robusto de Excepciones:**
   - Bloques `try / except` para validación de entradas de usuario (`ValueError`, `ZeroDivisionError`).
   - Definición y lanzamiento de excepciones personalizadas (`raise ListaVaciaError`, `NombreNoEncontradoError`, `TransaccionError`).

4. **Programación Orientada a Objetos (POO):**
   - Modelado de clases con estado y comportamiento (`class Arbol`, `class UsuarioBanco`).
   - Métodos constructores (`__init__`), encapsulación y gestión de operaciones entre instancias (transferencias bancarias y gestión de saldos).

5. **Lógica de Negocio y Utilidades:**
   - Procesamiento modular de texto con argumentos variables (`*args`).
   - Clasificación por tramos de notas y horarios.
   - Cálculo geométrico de áreas (`math.pi`).
   - Lógica de descuentos y cupones comerciales.
